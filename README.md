# Containous (Traefik Labs)

Containous SAS is the France-founded (2016) cloud-native networking company that created **Traefik**, the
open-source reverse proxy, ingress controller, and load balancer written in Go. It was surfaced through the
API Evangelist network as a portfolio company of **Balderton Capital** (which led its Series A alongside Elaia
Partners, 360 Capital, Kima Ventures, and OSS Capital). Containous later rebranded to **Traefik Labs**, and its
original `containo.us` domain now redirects to `traefik.io`.

This repo is the **company / parent profile**. The full product and API surface — OpenAPI, Kubernetes CRDs,
examples, vocabulary, and the Traefik Hub product line (API Gateway, API Management, AI Gateway, MCP Gateway) —
lives in the [api-evangelist/traefik](https://github.com/api-evangelist/traefik) repo.
